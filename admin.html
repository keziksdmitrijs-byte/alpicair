Доступ к GitHub

Изменения сохраняются прямо в репозиторий сайта. Для этого нужен личный токен GitHub — его создаёте вы сами, он хранится только в этом браузере.

  1. Откройте github.com → Settings → Fine-grained tokens
  2. Repository access: Only select repositories → alpicair
  3. Permissions → Repository → Contents: Read and write
  4. Создайте токен и вставьте его ниже
